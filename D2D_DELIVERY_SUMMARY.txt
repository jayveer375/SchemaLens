NEW TABLE: d2d_diagrams (13th table)
───────────────────────────────────

Columns (18 total):

- input_content_preview (TEXT) - first 500 chars
- mermaid_syntax (TEXT) - generated code
- generated_sql (TEXT) - optional for ER/Schema
- recommended_type (VARCHAR 50) - auto-detected
- user_selected_type (VARCHAR 50) - user's choice
- status (VARCHAR 20) - 'processing', 'completed', 'failed'
- error_message (TEXT)
- processing_time_ms (INT)
- created_at (TIMESTAMP DEFAULT NOW())
- updated_at (TIMESTAMP DEFAULT NOW())

Indexes (4 total):
- idx_d2d_diagrams_user_id (for user lookups)
- idx_d2d_diagrams_diagram_type (for filtering by type)
- idx_d2d_diagrams_created_at (for sorting recent)

4. API ENDPOINTS (6 Backend + 6 Frontend Proxies)
================================================================================

BACKEND ENDPOINTS:
──────────────────

1. POST /api/d2d/analyze-image
   Input: user_id, image_id
   Output: diagram_uid, recommended_type, confidence
   Premium: Yes (402 if not Pro)
   Rate Limit: 100/hour
   Time: <30 seconds

2. POST /api/d2d/analyze-document
   Input: user_id, file_id
   Output: diagram_uid, recommended_types[], confidence
   Premium: Yes
   Rate Limit: 100/hour
   Time: <30 seconds

3. POST /api/d2d/analyze-text
   Input: user_id, text
   Output: diagram_uid, recommended_types[], confidence
   Premium: Yes
   Rate Limit: 100/hour
   Time: <10 seconds

4. POST /api/d2d/generate
   Input: user_id, diagram_uid, diagram_type, include_sql
   Output: mermaid_syntax, generated_sql, processing_time_ms
   Premium: Yes
   Time: <10 seconds

5. GET /api/d2d/diagrams/{user_id}
   Query: limit, offset, type (optional filter)
   Output: Array of diagrams with pagination
   Premium: Yes

6. DELETE /api/d2d/diagram/{diagram_uid}
   Input: diagram_uid, user_id
   Output: success message
   Premium: Yes
